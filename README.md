# Tiny Stack VM

Interpreter for make.fun's tiny stack ISA v1 (kit ISA.md): wrapping 32-bit
arithmetic, 256-value stack, branches, calls, 256-word memory, IO, all ten
traps, exact exit codes. One TypeScript file (main.ts, Node 22) answers all
40 instances of a set in one run, byte-exact vs the reference VM: 40/40 practice.
